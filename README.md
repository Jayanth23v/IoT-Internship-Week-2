Internet of Things (IoT) – Week 2

Sensors & Microcontrollers

This repository contains my Week 2 assignments and mini-project completed as part of my IoT internship using the Wokwi online simulator.

Assignments

The assignments cover:

1. Temperature and Humidity Monitoring using DHT11/DHT22
2. Distance Measurement using Ultrasonic Sensor
3. Motion Detection using PIR Sensor
4. Automatic Night Lamp using LDR
5. Buzzer Alarm System
6. Display Sensor Data on Serial Monitor
7. Trigger LED using Sensor Input
8. Documentation of Sensor Readings

Smart Environment Monitoring System

Features:

- Alert Notifications
